# Franco Ficara Repository

**Software gratuito, idee digitali e strumenti per tutti.**

Catalogo ufficiale di **Franco Ficara Digital Studio**. Questo repository conterrà il portale web pubblico e le informazioni sulle versioni dei programmi. I download saranno abilitati solo dopo verifica dei pacchetti.

## Pubblicazione dei programmi

1. Verificare che il programma funzioni e non contenga password, dati personali o chiavi API.
2. Caricare il pacchetto in una GitHub Release ufficiale del progetto.
3. Aggiornare il catalogo con versione e link reale dell'asset; non usare collegamenti inventati.

**Nota:** gratuito non significa automaticamente open source. Le condizioni d'uso e le licenze dei singoli programmi devono essere definite esplicitamente prima della distribuzione.
