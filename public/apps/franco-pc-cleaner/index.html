Seleziona una cartella o alcuni file e confrontali per individuare copie identiche. Il confronto avviene nel tuo browser: i file non vengono caricati su un server e non viene cambiato nulla sul computer.

Attenzione: questa è un'anteprima web limitata alla ricerca dei duplicati, non Franco PC Cleaner per Windows 3.5. Non sposta, non elimina e non mette file in quarantena. Il programma Windows completo è ancora in collaudo.
